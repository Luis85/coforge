# Task: Dispatch viewer alerts into an OBS Browser Source

- Status: implemented; final qualification and merge are tracked in [PR #42](https://github.com/Luis85/coforge/pull/42).
- Journey in BRIEF.md: OBS Alerts URL and manual/event-triggered media templates (owner, 2026-10-29).

## Why

The streamer needs to react to stream events with reusable viewer-facing text and media without leaving CoForge.

## Traceability

The imported traceability file contains no requirement/interaction entries. Product acceptance is tracked as ALERTS-01–06 in the dedicated alerts tests; no generated obligations are changed.

## Acceptance

- Save/edit/delete templates with literal `{{variable}}` substitution, image/GIF, audio and video, duration and volume. Failed saves retain drafts and previous definitions.
- Copy a stable vault-local HTTP Alerts URL into an OBS Browser Source. Idle output is transparent. Multiple alerts queue in order with bounded memory; reconnect/reload never replays old alerts.
- Fire a saved template manually with variables, or explicitly enable a binding to a named committed CoForge event. Invalid or missing variables never publish partial content.
- The source is read-only and only receives rendered cues and explicitly selected media. No private state, credentials, raw event records or arbitrary vault files are served. Stop clears output; unload closes the listener.
