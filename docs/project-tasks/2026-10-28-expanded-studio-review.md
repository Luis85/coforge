## Data integrity and privacy

New Request Objects apply to future requests only. Guarded note edits preserve stable identity, unrelated frontmatter and body bytes, and invalidate stale screening/agent input. Canonical class/schema/value tests cover zero, false, defaults, revisions and external edits. Private custom values remain excluded from public projections.

Private projects are excluded from viewer discovery, command routing and all derived capture/site data. Existing authored Twitch messages cannot be recalled, and already deployed Pages need republishing. Visibility-only privacy changes remain possible during active work; mixed configuration changes retain the pending-work gate. Export revocation uses exact ownership evidence and serializes publication, preserving unrelated human files.

Linked Council assessments capture screened, trusted semantic request facts and omit raw account/voter identities, paths and full diffs. Vote arrivals do not invalidate an assessment, while human proposal and custom-field changes do. Protected linkage prevents stripping editable metadata to bypass the item check.
