# Stream statistics surface

Mode: Operate. Extend CoForge's existing Obsidian-native visual world: system UI font, restrained purple accent,
theme-derived surfaces/borders/text, existing form controls and navigation. No replacement brand or new font.

The first viewport answers which stream, which metric, and which earlier sessions are being compared. A wide
timeline is the primary surface, with direct date legends and a keyboard inspection control. Comparison rows
and recorded coverage explain differences without inventing growth claims or making every number a card.
At narrow widths the controls stack; the chart recalculates pixel coordinates/ticks and tables scroll locally.
Color and line dashes both identify sessions. Missing observations remain gaps; source-backed zero stays zero.
